## 1. Introduction

Every **backend action** the product needs for API contract design. Pipelines run **in-process** (`asyncio.create_task`) — no arq worker.

| Part | Scope |
|------|--------|

| **II** | Analyst journey actions (same app) |
| **III** | Shared pipeline, health |
| **IV** | Audit — orphan buttons and APIs |

## Part III — Shared pipeline & background jobs

| Action | What it does | Triggered by | Object affected | Notes |
| -------- | -------------- | -------------- | ----------------- | ------- |
| Sweep orphan runs | Mark stale `running` runs failed | App startup (`lifespan`) | Deep Research Run, Run | `orphan_sweeper` |
| Log run event | Append pipeline stage line | All run executors | Run Event | `emit()` → DB + JSONL |
| Log engine call | Audit vendor request/response | All engine clients | Engine Call | 100KB truncate |
| Execute cluster run | Exa → dedup → articles → Sonnet enrich | Run cluster/query API | Run, Search Result, Article | `web_discovery.py` | In-process task |
| Execute deep research pipeline | Parallel+Exa+Diffbot → Sonnet → save | Research run API | Deep Research Run, Company, Card, Source, Profile Completeness Parameter | `research.py` | In-process task; BD signals/scores not persisted |
| Enrich article (Sonnet) | Summary + mentioned_companies + `companies` rows | During web discovery run | Article, Company | `web_discovery.py` + `discovery_companies.py` | `ENRICH_CONCURRENCY=4` |
